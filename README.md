# Rinde Plus — Redesign

Site responsivo com versões em espanhol (`index.html`), português (`index-pt.html`) e inglês (`index-en.html`).

## Executar localmente

Com Node.js instalado:

```sh
npm run preview
```

Abra o endereço informado pelo servidor. Os arquivos estáticos e efeitos compilados já estão incluídos em `assets/`.

## Estrutura

- HTML, CSS e JavaScript na raiz.
- Imagens, vídeos e módulos em `assets/`.
- `mobile.html`: prévia em formato celular.
- `LEIA-ME.md`: informações adicionais da entrega.

Proposta visual de redesign para apresentação à empresa.
